# Python Practice

Small Python exercises I write to learn the language. Each script is a single file that runs on its own.

## About

Information Technology student at the University of Turku, learning Python with a focus on Computer Vision.

## Exercises

| File | What it does |
|---|---|
| `even_odd.py` | Asks for an integer and tells whether it is even or odd, with input validation |
| `fizzbuzz.py` | Prints numbers 1 to 50, replacing multiples of 3, 5 and 15 with Fizz, Buzz and FizzBuzz |
| `word_count.py` | Reads `text.txt` and prints the ten most common words |
| `temperature.py` | Converts between Celsius and Fahrenheit using a simple menu |
| `stats.py` | Calculates the minimum, maximum and average of a list of numbers |

## How to run

Requires Python 3.9 or newer.

```
python even_odd.py
```

`word_count.py` needs `text.txt` in the same folder.
